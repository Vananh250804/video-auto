# video-auto

Edit video tự động bằng FFmpeg, Remotion và Claude skills. Chạy trên máy cá nhân (Windows, macOS).

## Bắt đầu nhanh (khách hàng)

1. `git clone` repo này, `cd video-auto`, `npm install`.
2. Mở thư mục trong **Claude Code**.
3. Gõ `/video-auto`. Claude hướng dẫn cài đặt từng bước (kiểm máy, khóa ElevenLabs, Telegram, Google Drive, video thử), rồi edit video cùng bạn.
