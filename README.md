# video-auto

Edit video tự động bằng FFmpeg, Remotion và Claude skills. Chạy trên máy cá nhân (Windows, macOS).

- Cài đặt nhanh: mở Claude Code trong thư mục này, Claude tự kiểm tra máy và hướng dẫn từng bước. Hoặc chạy `node scripts/doctor.mjs`.
- Cài đặt chi tiết: [docs/setup.md](docs/setup.md)
- Cấu trúc và quy tắc: [CLAUDE.md](CLAUDE.md)
